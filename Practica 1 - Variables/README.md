# Practica 2

### Enunciat

Exercici 1. Escriu un enunciat i desenvolupa l’algorisme en C# que compleixi les següents característiques.
 Hi ha d’haver dos tipus diferents de variables (mostra la part del codi on això passi).
 Hi ha d’haver com a mínim dos entrades de valor per teclat.
 Hi ha d’haver un mostrar per pantalla com a mínim.
 Hi ha d’haver la utilització de dos operadors aritmètics com a mínim.
 Hi ha d’haver una la concatenació d’strings.

Exercici 2. Escriu un enunciat i desenvolupa l’algorisme en C# que compleixi les següents característiques.

 S’ha de resoldre una formula (per calcular volums, velocitats...) Has de demanar els valors necessaris per la seva correcta resolució, així com el càlcul de les unitats correctes. (Es comprovarà també la bona utilització de variables)

Exercici 3. Fes un algorisme en C# que trobi les solucions d’una equació de segon grau del tipus 0=AX2+BX+C (sabent que l’arrel quadrada d’un número x es calcula amb Math.sqrt(x). A, B i C s’han de poder entrar per teclat (Es comprovarà també la bona utilització de variables i que el codi estigui comentat).
